Сначала запустить проект gRPC.Service,
а потом gRPC.Client

Для создания нового сервиса нужно создать новый протофайл: customers.proto
и затем новый сервис для него: CustomersService

После изменений важно делать ребилд, т.к. в gRPC используются автогенерируемые файлы


gRPC — для внутреннего синхронного трафика между сервисами:
- строгий контракт в proto
- кодогенерация клиентов
- HTTP/2
- бинарная сериализация
- заметно дешевле по latency и трафику
- есть стриминг
